The packet is bounded64KiB/depth16 with finite groups, exact UUID/digest/timestamp shapes and captured currency/precision. Recognition of this captured shape never proves sealed placement or payment; Q06 must resolve the exact private binding and original context digest.

The order/item marker `_cetech_de_delivery_quote_format` uses native `meta_exists` plus bounded native raw metadata inspection, because WooCommerce filters physical null metadata out of that method. Null or empty present metadata is not absence. Marker presence or the reserved member requires the known packet before legacy fallback. Unknown format, malformed mandatory receipt, missing packet and incompatible line/order packet refuse. A quote-owned order's managed lines require matching identities/receipt digests. Genuine absence preserves existing V1/V2/C05 raw historical bytes and facts. Reads never backfill metadata, reconstruct current pricing, or overload an old reference. Historical/customer projections use captured money and strip protected identities/provenance; diagnostics remain finite.

Compiled reader support is an exact format/profile capability, explicitly `reader_only`. It is not storage readiness, placement readiness or writer activation.
