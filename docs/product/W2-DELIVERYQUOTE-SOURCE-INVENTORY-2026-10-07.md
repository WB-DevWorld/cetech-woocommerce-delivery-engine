## Native primary-source boundaries

Pinned official [WooCommerce11.1.2 checkout](https://github.com/woocommerce/woocommerce/blob/11.1.2/plugins/woocommerce/includes/class-wc-checkout.php): order_created follows save, raw freeze precedes final processed; resume_order precedes deletion/recreation of pending-order items. [StoreAPI Checkout](https://github.com/woocommerce/woocommerce/blob/11.1.2/plugins/woocommerce/src/StoreApi/Routes/V1/Checkout.php) validates native totals before materialization, synchronizes request before processed/paid/free, and GET/PATCH can reuse a pending order. [Form handler](https://github.com/woocommerce/woocommerce/blob/11.1.2/plugins/woocommerce/includes/class-wc-form-handler.php) authorizes order-pay before before_pay_action; that action is outside its gateway try/catch. Hook names are not substitutes for actual route proofs.

[WordPress nonce guidance](https://developer.wordpress.org/apis/security/nonces/) says nonces do not authorize access; default guests share userID0. [Woo Cart Token guidance](https://developer.woocommerce.com/docs/apis/store-api/cart-tokens/) identifies native cart ownership context. Proposed quote binding is a current server-derived site/user/session capability, not a submitted identifier or nonce. Private loaders cannot run at an early generic REST callback before Woo session/nonce authorization.
