# Delivery Engine Standard Test Data

Fill this page as the campaign setup is created.

Do not assume every item below already exists.

If an item does not exist when the first relevant test is reached, create the minimum safe test fixture and record it here.

Later testers should reuse these fixtures unless a case requires different data.
