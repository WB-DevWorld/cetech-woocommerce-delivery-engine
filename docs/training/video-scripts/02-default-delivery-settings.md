**Learning objective:** Open Default Settings, explain inheritance, review fulfilment and delivery choices, save safely, and confirm with Preview.

## Scene 1 — Open Default Settings

**What is visible:** Delivery Settings → Default Settings.

**Narration:** Default Settings are the store-wide values products can inherit. When a product has no special override, it follows these defaults.

**Action being performed:** Open Delivery Settings, Default tab; pause.

**Key teaching point:** Defaults reduce repetitive product edits.

## Scene 2 — What defaults mean

**What is visible:** Fulfilment availability / fulfilment choice fields.

**Narration:** Here you set fulfilment availability and how fulfilment is chosen. These labels should match what your store actually offers customers.

**Action being performed:** Slow scroll; highlight fulfilment-related fields without editing unless authorised.

**Key teaching point:** Use clear operational language — Fulfilment, not internal jargon.

## Scene 3 — Delivery method and offers

**What is visible:** Delivery method / delivery offers controls.

**Narration:** Defaults also cover delivery method and which delivery offers products can use. Incomplete offers or pricing must never silently become free shipping.

**Action being performed:** Show offer-related controls; pause.

**Key teaching point:** Missing configuration is not free shipping.

## Scene 4 — Recommended workflow

**What is visible:** Save control and link toward Preview.

**Narration:** Recommended workflow: set clear defaults, save, then open Delivery Settings Preview for a sample product. Prefer fixing defaults instead of overriding every product.

**Action being performed:** Point to Save; do not save experimental changes on production without approval.

**Key teaching point:** Save then Preview.

## Scene 5 — Preview result

**What is visible:** Preview for a QA product.

**Narration:** In Preview, confirm the product is Currently using Default when no product override exists, and that status is Ready when configuration is complete.

**Action being performed:** Open Preview for QA #39705 if available.

**Key teaching point:** Preview proves inheritance.
