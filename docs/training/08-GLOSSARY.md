# Glossary (plain language)

**Audience:** All staff  
**Version:** 1.0.0-rc.2

Terms match what you see in the Delivery Engine screens. Technical implementation words are avoided unless they appear in the UI.

---

**Fulfilment** — Where/how the item is available for the customer path (for example In store, In warehouse, International fulfilment).

**In Store** — Fulfilled from store stock / store path.

**In Warehouse** — Fulfilled from warehouse stock / warehouse path.

**International** / **International fulfilment** — Fulfilled through the international path your store supports.

**Delivery** — The customer receives the item by delivery (not store pickup).

**Store Pickup** — The customer collects the item from a pickup location.

**Delivery Offer** — A delivery choice shown to the customer (the public name they select).

**Rate Card** — The rule that sets the delivery fee for a destination zone + delivery offer (and related matching details).

**Destination Zone** — A geographic coverage area used to decide which delivery pricing applies.

**Default Setting** — Store-wide delivery values products can inherit.

**Product-Specific Setting** — Delivery values set for one product when it should differ from the default.

**Variation-Specific Setting** — Delivery values set for one variation when it should differ from its parent product.

**Inherit** / **Use inherited setting** — Keep the value from the level above (Default → Product → Variation).

**Override** / **Set a different value here** — Replace the inherited value at this level.

**Disable** / **Turn off** — Intentionally provide no value for that field at this level (where supported).

**Estimated Delivery** — The customer-facing timing text for delivery (or **Ready for pickup** when pickup applies).

**Delivery Group** — When several cart items share a compatible delivery path, they can share one delivery charge (for fixed-per-shipment pricing). Staff usually see the result as one Delivery shipping line rather than a separate “group ID”.

**Delivery information** — The staff panel on a WooCommerce order showing the delivery details saved for that order.

**Legacy Delivery Rules** — The older product-rule screens. Normal staff should usually leave them alone and use **Delivery Settings** instead.

**Needs configuration** — The setup is incomplete; customers may not get a valid delivery choice until it is fixed.

**Ready** — The delivery setup for that view looks complete enough to apply.

**Configuration problem** — Something is invalid and needs correction (escalate if unsure).
