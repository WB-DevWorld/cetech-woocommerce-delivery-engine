# CETECH Delivery Engine — Staff Training

**Plugin:** CETECH WooCommerce Delivery Engine **1.0.0-rc.12** (schema **6**)
**Everyday home:** WordPress admin → **Delivery Engine → Overview**

Staff training for the actual RC.12 plugin. You do **not** need PHP, databases, or plugin architecture.

**Start here:** [00-START-HERE.md](00-START-HERE.md)

Location Packs are a **directory of places**, not delivery prices. Delivery Areas and Coverage Groups describe **where** you serve. Delivery Charges set **money**. See the diagram in Start here.

Every implemented feature must be trained or ticked on the live site: [13 — Feature coverage and confirmation](13-FEATURE-COVERAGE-AND-CONFIRMATION.md).

Screenshots and videos are not recaptured for RC.12 yet. Follow these written guides on the live screens. Older RC.2 images or videos are out of date.

This published copy is synced from `docs/training/` in the plugin repository. After changes land on `master`, `.github/workflows/sync-training-docs.yml` publishes them to `wbdevworld/cetech-woocommerce-delivery-engine-training`.

Plugin repository: https://github.com/WB-DevWorld/cetech-woocommerce-delivery-engine
