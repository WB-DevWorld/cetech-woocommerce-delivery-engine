Permissions

WordPress roles control who can manage Delivery Engine. These capabilities are assigned by the plugin and are not edited on this screen.

RoleAccess
AdministratorFull Delivery Engine access, including Technical Diagnostics. This access is fixed and is not removable from this screen.
Shop ManagerNormal delivery management (settings, areas, charges, product exceptions) without Technical Diagnostics.

Technical Diagnostics remains separately permissioned for Administrators.

Help

If delivery rates are not showing at checkout, check these first.

  1. Complete the Setup Guide so site-wide defaults are saved.
  2. Make sure at least one Delivery Area exists.
  3. Make sure at least one Delivery Option exists.
  4. Make sure at least one active Delivery Charge exists.
  5. In WooCommerce Shipping, add the CETECH Delivery shipping method to the shipping zone that serves your customers.
  6. Activate Delivery Engine, then test with a customer address that matches a configured delivery area.
