# RC.3 Admin UI — Owner Review Checklist

Review each screenshot in `docs/review/rc3-admin-ui/screenshots/` against `Design Reference/` and the intended Stage 13B staff experience.

All captures are **FIXTURE RENDER** (sample catalog), **NOT LIVE WORDPRESS**. Judge the implemented UI, not the yellow fixture banner or harness top navigation.

This pack is Stage 13B-R2. Architecture is already approved. Review remaining owner UX corrections only.

Mark each box. Add comments under the screen. Approve only if you would ship that screen.

## How to use

1. Open the PNG.
2. Compare with the Design Reference named on that screen (if any).
3. Tick every criterion that passes.
4. Write OWNER COMMENTS even if you approve.
5. Do not treat fixture catalog names/counts as production data.
