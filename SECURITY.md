# Security Policy

## Supported line
Security fixes target the current supported release/candidate line declared in `docs/STATUS_CURRENT.md`. Historical release tags are immutable.

## Reporting a vulnerability
Do not publish exploit details in a public issue. Contact the WB DevWorld/CETECH maintainers through an approved private organizational channel and include:
- affected version/SHA;
- reproduction conditions;
- impact;
- minimal proof of concept where safe;
- any known mitigation.

## Public repository notice
This repository is public to support the collaboration/protection features available on the current GitHub plan. The Composer package declares a proprietary license. Public source visibility does not itself grant permission to copy, redistribute, sublicense, or commercially reuse the software.

Never commit production credentials, customer data, private supplier/origin data, licensed third-party plugin packages, secrets, or environment exports.
