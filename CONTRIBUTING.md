# Contributing

1. Read `AGENTS.md`, `OWNERSHIP.md`, `CURRENT-WORK.md`, `docs/AUTHORITY.md` and your workstream package.
2. Work only on an explicitly authorized task from a clean known base.
3. Use `ws1/**`, `ws2/**`, `ws3/**` or `fix/**`; multi-owner milestones use neutral `batch/**` integration branches.
4. Keep commits scoped. Preserve unrelated work. Never force-push another developer's branch.
5. Run the task's required checks and inspect the diff before handoff.
6. Handoff exact base/head SHAs, changed paths, evidence, environment/side effects, blockers and next action.
7. Critical WS3-authored changes require another competent human reviewer.
8. No AI approval or green CI substitutes for human production authorization.
